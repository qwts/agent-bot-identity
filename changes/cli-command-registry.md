- Every `agent-bot` command registers once in a command registry: its name, whether it is public or internal, the module it runs (or the function that answers it) and its subcommand routes. The parser accepts exactly the registered names and the dispatcher resolves each invocation through the registry, replacing the separate command sets, the command-to-module map and about forty dispatch branches. Command names, arguments, help, exit codes and `--json` output are unchanged. It is the in-place form of HQ plugin registration (HQ plan §4.2, Stage 0 row 9, #1394).
