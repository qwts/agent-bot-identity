- `scripts/cloud/setup.sh` sets up agent-bot on a fresh short-lived Linux host, so a Claude Code cloud environment's setup script is one line. It installs the Linux bundle for the user (the latest release by default, `--version vX.Y.Z`, or `--from-checkout DIR` for an unreleased change; release archives are checked against SHA256SUMS), applies the organization profile (`--profile PATH|https-URL`, bootstrap `--machine-only` with the systemd load skipped), and registers `agent-bot cloud up` / `cloud down` as the Claude Code SessionStart / SessionEnd hooks. It needs no root, reads no secret and can run again. `docs/server-mode.md` documents the one-line environment.
