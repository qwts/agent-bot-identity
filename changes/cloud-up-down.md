- `agent-bot cloud up|down|install-hooks` brings a short-lived machine (a Claude Code cloud container, a CI runner) to a working state and takes it down again. `up` is idempotent: it starts the identity daemon when it is not running and enrolls the device with the agent-bot server when it is not enrolled, for the App the detected harness maps to (or `--harness` / `AGENT_BOT_SERVER_HARNESS`). It enrolls with `AGENT_BOT_ENROLL_TOKEN` when set, and otherwise starts the device grant in the background and prints the approval link at once; the daemon restarts once the grant is approved. `down` stops the daemon and unenrolls (`server logout`). `install-hooks` registers `cloud up --hook` and `cloud down --hook` as Claude Code SessionStart and SessionEnd hooks; `--hook` prints hook JSON carrying the approval link and never blocks the session. `agent-bot start` now creates the soul and its worktree when agent-comms is absent or unpaired, and says so, instead of failing; `join --wake` still requires agent-comms.
