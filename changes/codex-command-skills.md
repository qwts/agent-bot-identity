- `agent-bot soul build` now renders a soul's commands for Codex as skills in the same shape Codex's own command importer uses, in `.agents/skills/source-command-<name>/SKILL.md`. A command that uses arguments, shell or `@` file includes is reported under `unsupported.commands` for Codex instead. Only marked files in `.agents/skills/` are the builder's: other skills there are never changed or removed, and an unmarked file where a command skill would render is a conflict. The format-2 ignore list appends `.agents/skills/`, and souls carrying an earlier list still validate (#378).
