- `agent-bot soul build` now renders a soul's commands for Codex as skills in `.agents/skills/source-command-<name>/SKILL.md`, using the same shape as Codex's own command importer. This happens only when the soul's `preferredHarnesses` names `codex` or is empty. Qwen Code and OpenCode also read that folder, so the build report lists every command they would see twice under `duplicates.commands`. A command that uses arguments, shell or `@` file includes is reported under Codex's `unsupported.commands` instead. Only marked files in `.agents/skills/` belong to the builder: it never changes or removes other skills there, and an unmarked file where a command skill would render is a conflict. The format-2 ignore list appends `.agents/skills/`, and souls carrying an earlier list still validate (#378).
