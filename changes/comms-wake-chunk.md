- A broker `wake` event carrying more than 512 message ids — a whole mailbox backlog unioned after a fresh agent-comms pairing — no longer fails `wake dispatch`: the daemon splits it into ordered wakes of at most 512 ids each, each with its own frame, report and receipt, so no message is dropped and none is re-woken out of order. The event's own bound is a 4096-id sanity ceiling; each dispatched wake stays within the wire's 512.
