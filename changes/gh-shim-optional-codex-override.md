- `agent-bot bootstrap --with-gh-shim` and `install-gh-shim` no longer fail when the optional Codex runtime override directory exists but is not writable by this account. The managed gh shim is installed as before, and the override is reported on its own: a `bootstrap.codex_gh_override` warning (`codex-gh-override-unwritable`) naming the directory and its owner. The directory's mode and owner are never changed (#1374).
