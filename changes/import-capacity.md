- `agent-bot soul env import` refuses an archive whose declared size or entry count would not fit on the souls root's filesystem with 256 MiB and 4096 files to spare (`import-insufficient-space`). It checks before asking the owner and again before extracting, and the owner's prompt now names the archive's entry and byte totals, so an archive that expands to more than the disk can hold no longer fills it (#1070).
