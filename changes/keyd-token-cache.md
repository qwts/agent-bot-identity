- Cache minted GitHub App installation tokens in `agent-bot-keyd` Keychain (#1340): `keyd` now caches minted installation tokens per `(agentId, appSlug, scope)` in its ACL-protected Keychain store (`agent-bot.keyd.<agentId>` / `github-token-cache/<slug>`) and reuses them across `credential` and `git_credential` calls while more than 5 minutes of lifetime remain, exposing `token_cache_get`, `token_cache_put`, and `token_cache_evict` under daemon-signed grants and evicting cached tokens on `DELETE /v0/binding`, `owner/remove`, or device revocation.
