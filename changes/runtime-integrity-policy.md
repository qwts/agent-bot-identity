- Managed Python now installs only the python-build-standalone archive the catalog pins for each platform: uv is held to that one download and refuses bytes with any other digest, and the install receipt records the digest. A soul can set `runtimes.integrity: "required"` in `soul.json` to refuse a uv tool without a `lock` and to reinstall a Python that has no recorded digest. Without that setting, such installs still work and are labelled unverified in `soul runtimes` and `soul env` (#617).
