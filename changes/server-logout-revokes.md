- `agent-bot server logout` now unenrolls the device at the server: it calls `POST /api/daemon/revoke` on the server the device enrolled with, then removes the local key, device record and pin. A device already revoked or expired counts as done, an unreachable server still removes the local files and exits 1 naming `/devices`, and `--local-only` keeps the old local-only behaviour. `scripts/e2e-server.mjs` revokes through the same documented route instead of `DELETE /api/daemon/device`, which the server does not serve. `docs/server-mode.md` adds a cloud-session section: per-session enrollment and logout, why the container's proxy keeps local GitHub writes from acting as the bot, and the agent-bot server's MCP GitHub tools.
