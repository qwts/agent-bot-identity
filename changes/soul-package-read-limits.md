- Soul-package reads are now bounded by default (`SOUL_PACKAGE_LIMITS`: 8192 entries, 64 MiB in total, 8 MiB per file, 32 directories deep), the same bounds skill status and skill search already applied. This covers package validation, revision computation, template spawn and the daemon's package launch, the build's read of existing generated-harness output (which launch runs), and the destination walk of `soul revision edit --apply`. Before, they walked and read a package without limits. A package past a limit fails with `package exceeds read limits: …`, naming the limit. Validation hashes the one snapshot it read instead of walking the package twice. The soul.json helpers behind `soul comms` and the credentials declaration no longer follow a symlinked soul.json, and read at most 8 MiB (#1069).
