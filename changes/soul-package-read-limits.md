- Every soul-package read is now bounded by default (`SOUL_PACKAGE_LIMITS`: 8192 entries, 64 MiB in total, 8 MiB per file, 32 directories deep), the same bounds skill status and skill search already applied. Before, validation, revision computation and template spawn walked and read a package without limits. A package past a limit fails with `package exceeds read limits: …`, naming the limit, and validation hashes the one snapshot it read rather than walking the package twice (#1069).
