- When agent-bot isn't installed (uninstalled mode), agent sessions can no longer run scripts, interpreters or task runners (`node`, `npm`, `make`, `./x.sh`, `bash x.sh`, `eval`, `xargs` and similar), because that code could push or write to GitHub as you where the hook can't see it. They're allowed only when both the git author and the `gh` login are in `AGENT_BOT_UNMANAGED_AUTHORS`. The source bootstrap launcher (`./agent-bot bootstrap …`, `node bootstrap.mjs …`) still runs, so an uninstalled checkout can finish installing (#1064).
