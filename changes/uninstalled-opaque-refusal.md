- When agent-bot isn't installed (uninstalled mode), agent sessions may now run only a bare read-only command (`ls`, `cat`, `git status` and the like), the checkout's own `./agent-bot bootstrap` launcher, or anything at all when both the git author and the `gh` login are in `AGENT_BOT_UNMANAGED_AUTHORS`. Scripts, interpreters and task runners are refused by structure rather than by a denylist, so wrapper flags, grouping, escapes, aliases, shell functions, `git -c alias='!…'` and the next unlisted interpreter can no longer slip a `git push`/`gh` write through as you (#1064).
