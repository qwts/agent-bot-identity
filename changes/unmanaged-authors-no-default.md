- The compiled `ai9d` default for the unmanaged-author allowlist is gone (#675). The committed git hooks, `doctor` and the generated harness wrappers' uninstalled fallback now use only `AGENT_BOT_UNMANAGED_AUTHORS` or the configured `settings.unmanagedAuthors` (the fallback reads the same config file, so a config-only policy is honoured in every dialect), which an organization profile's `settings.unmanaged_authors` projects into. With neither selected, every human-attributed commit and GitHub write in an uninstalled session is refused. `doctor` reports `unmanaged_authors_source: none` with the action to select a policy. Harness settings written by an older `sync-hooks` keep the old wrapper until the installer or `agent-bot sync-hooks` re-renders them.
